# Earth2Farm
Earth2Farm transforms NASA Earth-observation data into practical rice-planting guidance for farmers in Bangladesh. As monsoon patterns shift, traditional Aman rice planting calendars can become unreliable. Earth2Farm analyzes 25 years of NASA POWER daily rainfall data to detect actual monsoon onset, compares historical and recent periods using statistical analysis, and estimates how the shift affects the planting window. SMAP soil moisture and MODIS/VIIRS NDVI provide additional environmental context. The system then converts complex climate data into a simple recommendation telling farmers whether to plant earlier or later and by approximately how many days, with an SMS-ready version in Bangla or English.
